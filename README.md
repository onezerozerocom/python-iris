# IRIS 데이터 분석 실습

붓꽃(iris) 데이터로 **데이터 읽기 → 특성 분석 → 결측치 처리 → 이상치 처리 → 정규화**를 차례로 익히는 인터랙티브 학습지입니다. 학생은 코드의 빈칸을 채우고 **▶ 실행**을 눌러 결과를 확인한 뒤, 연습문제로 결과를 해석합니다. (교과서 65–74쪽)

원본: [python-iris](https://onezerozerocom.github.io/python-iris/)의 내용을 새 디자인으로 다시 만든 버전입니다.

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 페이지 뼈대 (제목, 흐름 스트립, 단계 목록, 본문 영역) |
| `style.css` | 디자인 (색상 토큰, 라이트/다크 모드, 반응형 레이아웃) |
| `app.js` | 데이터, 계산, 활동·연습문제 내용, 화면 그리기, 이벤트 처리 |

별도 설치나 빌드는 필요 없습니다. 외부에서 불러오는 것은 Google Fonts 글꼴뿐입니다.

## 실행 방법

- `index.html`을 브라우저로 열면 됩니다. 더블클릭으로 열어도(`file://`) 동작합니다.
- VS Code의 Live Server로 열어도 됩니다.
- 웹에 올릴 때는 세 파일을 같은 폴더에 두면 됩니다. GitHub Pages 등 정적 호스팅이면 충분합니다.

## 학습 구성

| 단계 | 내용 | 활동 | 연습문제 |
| --- | --- | --- | --- |
| 먼저 알아보기 | 붓꽃을 관찰해 볼까요? → iris.csv 전체 내용(결측치 표시 전환) → iris.csv 한눈에 → CSV에서 사용하는 속성 | – | – |
| 1. 데이터 읽기 | `pd.read_csv()`, `head()` | 01 | – |
| 2. 특성 분석 | `info()`, `describe()` | 02, 03 | 3문항 |
| 3. 결측치 | `isnull().sum()`, `mean()`, `fillna()` | 04, 05, 06 | 3문항 |
| 4. 이상치 | 상자그림, `np.percentile`로 IQR 계산, `drop()` | 07, 08, 09 | 3문항 |
| 5. 정규화 | `MinMaxScaler`, 정규화 전후 상자그림 | 10, 11 | 3문항 |

## 주요 기능

- **빈칸 채우기**: 빈칸마다 ①②③ 번호가 붙어 있습니다. **정답 확인**을 누르면 맞은 칸은 초록, 틀린 칸은 빨강으로 표시됩니다. 빈칸에서 Enter를 누르면 바로 실행됩니다.
- **실행 결과**: pandas 출력 형식 그대로 보여 줍니다. 빈칸이 비어 있거나 틀리면 `SyntaxError`, `AttributeError` 같은 파이썬식 오류가 나옵니다.
- **흐름 스트립**(위쪽): 활동을 실행하면 데이터 상태가 바뀝니다. 예: 결측 5칸 → 0칸, 150행 → 146행.
- **코드 패널**(오른쪽): 학생이 채운 빈칸이 바로 반영됩니다. "전체 노트북" 탭의 코드를 복사해 Jupyter에서 그대로 실행할 수 있습니다. "먼저 알아보기" 단계에서는 iris.csv 원문을 보여 주므로, 복사해서 `iris.csv`(UTF-8)로 저장할 수 있습니다.
- **왼쪽 도구**: 학습 진행률, 위에서부터 모두 실행, 이 단계 정답 채우기(교사용), 다시 시작.
- **진행 상황 저장**: 입력한 답, 실행한 활동, 연습문제 선택이 브라우저에 저장되어 새로고침해도 유지됩니다(`localStorage`의 `iris-lab-v1` 키). 브라우저마다 따로 저장되며 서버로 전송되지 않습니다.

## 동작 방식: 파이썬을 실제로 실행하지 않습니다

원본은 Pyodide(브라우저용 파이썬)로 코드를 실제로 실행했지만, 이 버전은 **데이터가 고정된 iris.csv이므로 결과를 JavaScript로 미리 계산해** 보여 줍니다. 그래서 로딩 없이 바로 결과가 나옵니다.

- 학생이 쓴 답은 정해진 정답 목록과 비교합니다. 띄어쓰기는 무시합니다. 예: `q3+1.5*iqr`와 `q3 + (1.5 * iqr)` 모두 정답입니다.
- 계산값은 pandas와 끝자리까지 같습니다. PetalLength 평균은 numpy와 같은 합산 방식(pairwise)으로 계산해 `3.7696551724137923`이 나옵니다.
- 이 데이터의 주요 결과값:
  - 결측치: PetalLength 5개 (20, 47, 63, 87, 113번 행)
  - SepalWidth: Q1 = 2.8, Q3 = 3.3, IQR = 0.5, 상한 4.05, 하한 2.05
  - 이상치: 4개 (15, 32, 33, 60번 행) → 제거 후 146행

## 수정하는 방법 (`app.js`)

| 바꾸고 싶은 것 | 위치 |
| --- | --- |
| 활동의 코드, 빈칸 정답, 설명, 실행 결과 | `ACTS` 객체. 코드 줄의 `{0}`, `{1}`이 빈칸이고, `blanks[k].a`에 정답을 여러 개 넣을 수 있습니다. |
| 연습문제 | `QUIZ` 객체. `a`는 정답 번호(1부터), `e`는 해설입니다. |
| 단계 제목, 목표, 개념 설명, 단계별 활동 순서 | `STEPS` 배열 |
| 단계 목록의 그룹 이름 | `GROUPS` |
| 색상, 글꼴, 간격 | `style.css` 맨 위 `:root`의 변수. 다크 모드 값은 바로 아래에 있습니다. |

### 데이터를 바꿀 때 주의

데이터는 `app.js` 맨 위 `IRIS_CSV`에 들어 있고, 통계량·이상치·정규화 결과는 이 데이터에서 자동으로 계산됩니다. 하지만 **연습문제 문구와 해설에 적힌 숫자**는 직접 쓴 것이라 데이터를 바꾸면 함께 고쳐야 합니다. 예: "150 - 145 = 5", "iqr = 0.5", "(146, 5)". 결측치는 PetalLength 열에 있다고 가정하고 만들어져 있습니다.

## 참고

- 한 파일만 필요하면 `style.css`와 `app.js` 내용을 각각 `<style>`, `<script>` 태그로 `index.html`에 다시 넣으면 됩니다. 이때 JS 문자열 안의 `</svg>`는 `<\/svg>`로 적어야 Live Server 같은 도구에서 화면이 깨지지 않습니다.
- 그래프는 SVG로 그리며, 상자·점에 마우스를 올리면 값이 표시됩니다.
